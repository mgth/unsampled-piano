# MIDI sources of the audio demos

`deb_clai.mid` — Claude Debussy, *Clair de lune* (Suite bergamasque), sequenced by
**Bernd Krüger**, <http://www.piano-midi.de> (edition 2011-08-20), licensed under
[Creative Commons Attribution-ShareAlike 3.0 Germany](https://creativecommons.org/licenses/by-sa/3.0/de/deed.en).
Unchanged here; `../demo_midi.py` cuts its first fourteen bars and the audio rendered from
them (`public/media/clair.mp3`, `public/media/mics-*.mp3`) is shared under the same licence.
